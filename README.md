# Student Feedback System

A full-stack web application developed as part of the Full Stack Development Internship at Cognifyz Technologies.

The project allows users to submit, edit, delete, and manage feedback dynamically using a responsive frontend and a Node.js + Express.js backend.

---

# 🚀 Features

- Responsive User Interface
- Feedback Submission Form
- Form Validation
- Dynamic DOM Manipulation
- CRUD Operations
- REST API Integration
- Persistent Data Storage
- Edit & Delete Functionality
- Toast Notifications
- Mobile Friendly Design

# ⚙️ Installation & Setup

## 1. Clone Repository

git clone https://github.com/Drakowarrior/student-feedback-system.git

## 2. Open Project Folder

cd student-feedback-system

## 3. Install Dependencies

npm install

## 4. Start Server

node server.js

OR

npm start

# 📌 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /api/feedback | Get all feedbacks |
| POST | /api/feedback | Add new feedback |
| PUT | /api/feedback/:id | Update feedback |
| DELETE | /api/feedback/:id | Delete feedback |
